What's New

What is actually in the build

No invented roadmap cards. These are features implemented in the repository and described by the app itself.

🎮

Game Session Manager

Approve background applications one by one. Security detection failures suspend nothing, protected processes are skipped, and restore checks process identity.

➕

Safe Process Rules

Rules store the executable path and keep new applications disabled until you approve them. A partial sweep is recorded instead of being hidden.

📊

Verified Restore

Sessions persist their process IDs, start times, thread IDs, detector state, and restore results so an interrupted launch can recover safely.

Features

Why BoneFish?

A short list of controls that exist in the current source tree.

🎮

Multi-instance launching

Allow more than one Roblox instance through the Integrations settings when your workflow needs it.

⚡

Performance presets

Apply the repository's stability, low-spec, balanced, and extreme performance settings with HDD and hardware-aware handling.

🎨

Bootstrapper themes

Choose built-in styles, light/dark presentation, custom themes, backgrounds, icons, and loading screens.

🏴‍☠️

FastFlags editor

Inspect and edit client settings through the graphical editor, with allowlist-aware presets and explicit save/apply actions.

📦

Mod import and presets

Import ZIP packages with structure and overwrite checks, or use the bundled cursor, sound, place, and emoji-font presets.

🔄

Crash reconnect prompt

When the watcher identifies a long Roblox crash session, it can offer to relaunch the last place and job.

🔒

Activity and account context

Activity tracking, Discord Rich Presence, optional cookie access, and account display are available as separate integrations.

🎯

Crosshair and hotkeys

Run a configurable crosshair overlay and control it with the global hotkey service.

🧹

Cleanup tools

Clean selected Roblox logs/cache and enable optional automatic cache cleanup without claiming a fixed amount of space.
